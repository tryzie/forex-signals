# ADR 0002: Java 25 LTS for the engine

- Status: Accepted (Phase 0, 2026-11-18)

## Decision
Java 25 LTS (Temurin). Virtual threads for feed I/O and writers, one single-threaded engine loop for
determinism. JDK 24+ removed virtual-thread pinning on `synchronized` (JEP 491). JDK built-ins are used
where possible: `java.net.http.WebSocket` for Deriv, `SSLSocket` for cTrader (no Netty).

## Consequences
The enforcer requires JDK `[25,26)`. One engine code path serves live, replay and backtest.
